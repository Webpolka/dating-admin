# Markdown-редактор шаблонов поддержки

## Назначение

Редактор для создания шаблонов ответов в чате поддержки. Шаблоны пишутся в **Markdown** (вариант B — «Markdown + чат-режим») и рендерятся как форматированный текст в чате поддержки.

## Файлы

| Файл | Назначение |
|---|---|
| `components/admin/markdown-editor.tsx` | Редактор с панелью кнопок + переключатель «Редактор/Превью» |
| `components/admin/message-content.tsx` | Рендерер контента (используется в чате и в превью редактора) |
| `components/admin/message-content.css` | Единый CSS для чата и превью |
| `app/(admin)/communication/support-templates/_components/template-editor-client.tsx` | Страница редактирования шаблона |
| `app/(admin)/communication/support/_components/support-chats-page-client.tsx` | Чат поддержки (использует `MessageContent`) |

## Как это работает

```
┌─────────────────────────────────────┐
│   MarkdownEditor (textarea)          │
│   Админ пишет:                       │
│   # Заголовок                        │
│   **жирный** текст                   │
│   - Список                           │
│                                      │
│   → onChange сохраняет markdown-     │
│     строку в formData.body           │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│   POST /api/admin/support-templates  │
│   body: "# Заголовок\n**жирный**..."  │
│   (в БД лежит markdown как есть)     │
└─────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│   MessageContent (в чате поддержки)  │
│   1. preprocessMarkdown(md)          │
│      - сохраняет пробелы/табы/       │
│        пустые строки через \u00A0     │
│      - вырезает code blocks           │
│   2. ReactMarkdown + remark-gfm +    │
│      remark-breaks рендерит HTML      │
│   3. CSS стилизует результат          │
└─────────────────────────────────────┘
```

## Что поддерживается

### Базовое форматирование

| Синтаксис | Результат |
|---|---|
| `**текст**` | **жирный** |
| `*текст*` | *курсив* |
| `~~текст~~` | ~~зачёркнутый~~ |
| `` `код` `` | `инлайн код` |

### Заголовки

```markdown
# Заголовок 1 уровня
## Заголовок 2 уровня
### Заголовок 3 уровня
```

### Списки

Маркированный:
```markdown
- Первый пункт
- Второй пункт
  - Вложенный (2 пробела в начале)
```

Нумерованный:
```markdown
1. Первый пункт
2. Второй пункт
3. Третий пункт
```

### Цитаты

```markdown
> Это важная цитата
> продолжается на второй строке
```

### Код

Инлайн: `` `код` ``

Блок:
````markdown
```
function hello() {
    return "world";
}
```
````

### Ссылки

```markdown
[текст ссылки](https://example.com)
```

### Изображения

```markdown
![описание картинки](https://example.com/image.png)
```

### Таблицы (GFM)

```markdown
| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Ячейка 1  | Ячейка 2  |
```

### Чек-листы (GFM)

```markdown
- [x] Выполнено
- [ ] Не выполнено
```

### Разделитель

```markdown
---
```

## Чат-режим (отличия от стандартного Markdown)

В стандартном Markdown:
- Множественные пробелы схлопываются в один
- Табы игнорируются
- Несколько пустых строк = одна пустая
- 4+ пробела в начале строки = code block

В нашем чат-режиме (через `preprocessMarkdown`):
- ✅ Множественные пробелы **сохраняются** (через `\u00A0`)
- ✅ Табы → 4 неразрывных пробела
- ✅ Ведущие пробелы в обычных строках **сохраняются**
- ✅ Несколько пустых строк **сохраняются**
- ✅ Одиночный `\n` = перенос строки (через `remark-breaks`)
- ❌ Строки с markdown-префиксами (`#`, `-`, `>`, `1.`) — ведущие пробелы НЕ трогаются (это синтаксис)
- ❌ Code blocks и inline code — НЕ обрабатываются (содержимое сохраняется как есть)

## Кнопки редактора

| Кнопка | Что делает | Toggle? |
|---|---|---|
| **B** (Bold) | Оборачивает выделение в `**...**` | Да — повторный клик снимает |
| *I* (Italic) | Оборачивает в `*...*` | Да |
| ~~S~~ (Strike) | Оборачивает в `~~...~~` | Да |
| `Code` | Оборачивает в `` `...` `` | Да |
| `Code Block` | Оборачивает в тройные backticks | — |
| **H1** | `# ` в начало строки | Да |
| **H2** | `## ` в начало строки | Да |
| **H3** | `### ` в начало строки | Да |
| **• List** | `- ` для каждой выделенной строки | Да |
| **1. List** | `1. `, `2. `, `3. `... | Да |
| **> Quote** | `> ` для каждой выделенной строки | Да |
| **🔗 Link** | `[текст](https://)` | — |
| **Tab** | Вставляет 2 пробела | — |

## Где используется

- **Создание шаблона**: `/communication/support-templates/new`
- **Редактирование**: `/communication/support-templates/{id}/edit`
- **Превью в чате**: при выборе шаблона в чате поддержки рендерится через `MessageContent`
- **Бабол сообщения**: после отправки сообщения рендерится через `MessageContent`
- **Превью в сайдбаре чата**: через `stripMarkdown()` — чистый текст без разметки

## Синхронизация стилей

**Один CSS-файл** (`message-content.css`) используется и в чате, и в превью редактора. Что видишь в превью → то увидишь в чате.

## Зависимости

```bash
npm install react-markdown remark-gfm remark-breaks
```

## Безопасность

- ❌ Никакого `dangerouslySetInnerHTML`
- ❌ Никакого HTML-санитайзера
- ✅ `react-markdown` строит безопасный React-DOM
- ✅ HTML-теги в сообщении экранируются (если админ напишет `<script>` — он выведется как текст)
