# Документация админки (dating-admin)

## Структура

| Раздел | Что внутри |
|---|---|
| [`dev-notes/`](./dev-notes/) | Рецепты для Laravel Tinker: генерация тестовых сообщений в чатах, проверка realtime и входящих в поддержку |
| [`components/`](./components/) | Документация отдельных компонентов (markdown-редактор шаблонов поддержки) |

## Зачем этот раздел

Раньше tinker-заметки лежали прямо в `_components/` страниц (рядом с
tsx-кодом) — они не являются частью бандла, но засоряли дерево компонентов
и путали при навигации. Все dev-рецепты теперь живут здесь.

## Правила

- Рецепты для тинкера/дебага → `dev-notes/` с говорящим именем файла.
- Документация компонента, которая длиннее комментария в коде → `components/`.
- Каждая заметка начинается с заголовка «Что делает» — чтобы по оглавлению
  было понятно, зачем она, без открытия файла.
